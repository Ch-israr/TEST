# AGENTS.md

This document provides an overview of the Glink Int project structure for developers and AI agents working on this codebase.

## Project Overview

A marketing/lead-generation website for **Glink Int**, a UAE-based self-storage and moving services company. The site's purpose is to convert visitors into enquiries (contact form) and WhatsApp conversations. Built with TanStack Start and deployed on Netlify.

### Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start (SSR) |
| Frontend | React 19, TanStack Router v1 |
| Build | Vite 7 |
| Styling | Tailwind CSS 4 (CSS-first `@theme` config) |
| Forms | Netlify Forms (AJAX submission + static skeleton) |
| Language | TypeScript (strict mode) |
| Deployment | Netlify |

## Editing Business Content (the most common task)

Everything a non-developer needs to change lives in **`src/config/site.ts`**:

- Company name, tagline, description
- `phone` / `phoneHref` — display number and `tel:` link target (leave `phoneHref` empty to hide call buttons)
- `whatsapp` — international format, no `+` (e.g. `"971501234567"`). Left empty, all WhatsApp buttons hide automatically; CTAs fall back to `#contact`
- `email`, `address`
- `mapsEmbedSrc` — Google Maps embed URL (Maps → Share → Embed → copy src); empty shows a styled placeholder
- `pricing` — headline rate (`pricePerSqFt`) and the three plan cards (size, price, features)
- `seo` — page title, meta description, keywords

Hero/section imagery uses Unsplash URLs defined at the top of each section component. Replace those URL constants with real company photos when available.

## Key Concepts

### Netlify Forms (SSR app — important!)

The contact form is a Netlify Form submitted via AJAX. Two files must stay in sync:

1. `public/__forms.html` — static skeleton so Netlify registers the form at build time. Field names must exactly match the React form (`name`, `phone`, `email`, `storage_size`, `service`, `message`, plus `form-name` hidden field and `bot-field` honeypot).
2. `src/components/sections/Contact.tsx` — the real form. Submits via `fetch('/__forms.html', ...)` with `Content-Type: application/x-www-form-urlencoded` (NOT to `/` — SSR would intercept it).

Breaking either file causes silent submission failures.

### File-Based Routing (TanStack Router)

Routes are defined by files in `src/routes/`. The route tree (`src/routeTree.gen`) is generated by the TanStack Router Vite plugin during build — do not edit it and do not worry about "cannot find module './routeTree.gen'" type errors before a build.

### Anchor navigation

Single-page site. Header/footer links point at section anchors (`/#storage`, `/#contact`, …). Section `id`s must match `src/components/Header.tsx` `links` array. `scroll-padding-top` and `scroll-margin-top` in `styles.css` keep anchors clear of the sticky header.

### Design system

- Colors are Tailwind theme tokens defined in `styles.css` under `@theme`: `navy-*` (brand blues), `accent` (gold #d9a441), `wa`/`wa-dark` (WhatsApp green), `mist`, `ink`, `ink-soft`
- Two section styles: light (`bg-white`/`bg-mist`) and dark (`bg-navy-950` + `.grid-lines` blueprint texture)
- Buttons: variants `primary`, `accent`, `whatsapp`, `outline`, `outlineLight`
- `.section-eyebrow` class for small uppercase section labels (add `text-accent` for dark sections)
- Scroll reveals: wrap content in `<Reveal>` (optionally `delay={ms}`); CSS handles animation, honors `prefers-reduced-motion`

## Conventions

### Naming
- Components: PascalCase files in `src/components/` and `src/components/sections/`
- Utilities/hooks: camelCase
- Routes: kebab-case files

### Styling
- Tailwind CSS utility classes only (v4 — theme via CSS `@theme`, no `tailwind.config` file)
- `cn()` helper for conditional classes
- No external icon library — inline SVGs

### TypeScript
- Strict mode enabled
- Import paths use `@/` alias for `src/*`
- Type-only imports use the `type` keyword
- `site` is `as const`, so empty-string fields narrow to `never` — use `as string` casts in derived helpers

### Content integrity rules
- No fake testimonials, reviews, statistics or certifications (deliberately omitted)
- No unsupported claims ("largest", "number one", "best in UAE")
- VAT always stated as "+ VAT", pricing marked as indicative
